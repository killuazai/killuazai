# Upload the GitHub profile

1. Create a new **public** repository named exactly `killuazai` under the `killuazai` account.
2. Do not add a starter README if you will upload this package immediately.
3. Upload `README.md` and the complete `.github/workflows/contribution-snake.yml` path.
4. Commit the files to the `main` branch.
5. Open the repository's **Actions** tab and run **Generate contribution snake** once.
6. Wait for the workflow to finish, then reload `https://github.com/killuazai`.

The typing banner displays immediately. The contribution animation appears after the first successful workflow run creates the `output` branch.
